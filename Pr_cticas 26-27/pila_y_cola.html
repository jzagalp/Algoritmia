La estructura

Práctica 1 · P1.2 · colaEnteros 
typedef int tipoElementoCola;

typedef struct celdaC{
    tipoElementoCola elem;
    struct celdaC *sig;
} celdaCola;

typedef struct tipoC{
    celdaCola* ini;
    celdaCola* fin;
} tipoCola;

Al contrario que la pila, una cola no es un puntero: es una estructura con dos, ini (el frente, por donde se desencola) y fin (el final, por donde se encola). Por eso las funciones reciben tipoCola* y escriben cola->ini. Mantener los dos coherentes entre sí es todo el trabajo de esta librería.

ini == NULL y fin == NULL — los dos campos a NULL. esNulaCola sólo mira ini; recuerda este detalle.
un solo elemento — ini y fin señalan la misma celda. La barra en el campo sig significa NULL.
5, 3, 7 — sale el 5 (por ini) y se encola detrás del 7 (por fin). Las flechas van siempre del frente hacia el final.

Las funciones

Tres casos, y el del medio es el que importa. Con varios elementos, fin no se toca. Con uno solo, fin señalaba justamente a la celda que desaparece: si lo dejas como está, se queda apuntando a memoria ya liberada y el siguiente encolar escribirá donde no debe. El programa no fallará en desencolar, fallará más tarde, y será difícil de encontrar. ¿Cómo puede saber la función, después de quitar la celda, que era la última?
